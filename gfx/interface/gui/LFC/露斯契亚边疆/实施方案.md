# 露斯契亚边疆实施方案

## 目标与范围

把「深入雨林」和「先驱者遗迹开发署」接入同一个地图大窗。玩家在图上点一个州，远征前可以筹备派遣，远征中可以看队伍状态，成功后可以从同一个州进入开发。顶栏遗物余额是全国性「遗物应用」的入口。帝国援军继续使用自己的入口。

**首版的核心体验是拿地。** 原有遭遇事件、补给与人力消耗、成功和失败结算沿用现有机制。远征成功后，预定目标州归入露斯契亚、成为核心并建立前哨站。开发和遗物应用沿用现有项目，数值调整、遗物配装和新剧情可在界面接通后另行讨论。

## 界面布局与操作

先以约 **1080 × 730** 的界面坐标搭骨架。顶栏约 56 高，左侧地图显示区约 **620 × 620**，右栏约 **360–380** 宽，其余用于留白、图例和边框。尺寸为起点，按地图实际取景和游戏缩放校准。

```text
┌─ 露斯契亚边疆 ─────────────── 进行中的远征 · 定位 ── [遗物库存] ─ [关闭] ┐
│                                                                         │
│    雨林测绘图                              右侧共用面板                  │
│    州界、河道、选中描边                     州详情 或 遗物应用            │
│    远征队、前哨站、在建项目、遗址           状态 → 信息 → 可执行操作     │
│                                                                         │
└─ 地图图例 ───────────────────────────────────────────────────────────────┘
```

- **打开和关闭**。在「深入雨林」决议区放一个打开大窗的按钮，大窗提供关闭按钮和 `Esc`。开启时优先定位正在远征的州，其次恢复上次选州，没有记录时显示沿海起点或默认总览。
- **点州**。立即选中该州并切回州详情。右栏从州名和状态开始，主要操作就在相关信息下面。相同位置预留给成本、限制和结果。一次只展开一个项目详情，列表超高时只滚动右栏。
- **点遗物余额**。右栏切到「遗物应用」，顶端显示全国库存及每月产量，再显示生效中的项目和可启用项目。地图及上次选中州留在屏幕上。「返回州详情」恢复原选州，点地图可直接换州。库存为零时仍可看项目效果和缺少的条件。
- **点远征定位**。仅在有任务时出现，选中真正的远征目标并回到州详情。按钮可放在顶栏，放不下时移到地图图例旁。

| 州详情状态 | 信息顺序与操作 |
|---|---|
| 未控制、当前可远征 | 州名、可派遣状态、前置条件，主按钮「筹备远征」。首版点按钮后进入现有补给、装备、人力筹备事件。 |
| 未控制、当前不可远征 | 说明缺少的条件，例如尚未与己方核心接壤，或已有队伍在筹备或远征。地图仍可选中该州。 |
| 当前远征目标 | 勘探进度、队伍剩余人力、补给、装备等级。危险值用字号、颜色和短标签提示。遭遇和结果继续由现有事件触发。 |
| 已控制 | 州现有的前哨站或开发阶段、在建项目，再列「地区建设」和「遗迹勘探」。标出项目的消耗、工厂占用、时长、前置条件与收益。 |
| 已有遗址 | 「遗迹勘探」组显示发现名称、规模和当地效果。正式版可加一张识别性强的遗址横图。同一个州仍显示建设信息。 |

地图以浅纸色、低饱和墨绿和灰蓝河道为主。**填色表达归属，描边表达选中和可派遣，符号表达行动或发现。** 可派遣描边比选中描边弱。州底色、边界和图例保持清楚，远征成功后由底色变化、前哨站标记和右栏新出现的开发入口共同反馈。

## 地图制作与交互接线

### 范围与坐标

- 首版地图范围取 **13 个州**，即 `1199–1208`、`280`、`504`、`505`。按原始省份图提取，这组州外接范围约为 **299 × 315 像素**，适合近方形取景。取景时在边界留出海岸、河道和地名所需的余量。
- 现有远征目标为 `1203–1208` 和 `280`。基建、移民和城市化的候选范围还含 `1202`、`504`、`505`。遗迹勘探有独立名单和条件。**显示在地图上、能派远征、能做某个项目是三件事**，按钮权限分别按现有条件判断。
- 从 `history/states` 读州的省份列表，用 `map/definition.csv` 映射省份颜色，在 `map/provinces.bmp` 提取掩膜。地图、州按钮、填色、描边和标点统一用一份裁切坐标。标点先由掩膜算出内部位置，小州或容易重叠的位置再人工校正。若引用 `map/rivers.bmp` 或地形图，同样用该裁切坐标。

### 层次与命中

从下到上绘制底图、州填色及命中区域、边界与选中描边、行动和遗址标记、地名。最上面三类装饰层设为鼠标穿透，州交互集中在州按钮。小州先用真实轮廓测试命中，再视结果加小标签入口。

参考伦敦危机的 `buttonType`、`transparencecheck = yes`、按变量切换贴图帧及独立选中描边。首个原型可为每州使用共坐标的全图透明贴图，便于核对对齐。如果之后改为州外接框贴图，生成时一并输出原点偏移，避免手填坐标。伦敦危机可参照 `interface/ENG_gui.gui`、`interface/ICON_ENG.gfx` 和 `common/scripted_guis/ENG_scripted_gui.txt`。

## 脚本结构与状态来源

代码沿用现有 LFC 文件。在对应文件的旧内容下方追加独立的「露斯契亚边疆」段落。有 `guiTypes`、`spriteTypes`、`scripted_gui` 等外层容器的文件，把新增段落放在容器内、最后一个右花括号之前。现有段落保留原顺序，原入口需要接共用逻辑时，只在对应调用点做必要改动。

**每个新增代码段加中文注释。** 段首标注 `# 露斯契亚边疆` 并说明用途；在选州与远征目标分离、项目扣费及结算归属、地图图层与点击区这些容易误改的地方，注明数据来源和为什么这样写。保留已有技术标识的命名风格。

| 路径 | 负责内容 |
|---|---|
| `interface/LFC_gui.gui` | 在现有界面下方追加入口、大窗、图例、州按钮和右栏控件。 |
| `interface/ICON_LFC.gfx` | 在现有贴图定义下方注册此项目的底图、州帧、描边与小标记。现有可复用图标直接引用其图形标识。 |
| `common/scripted_guis/LFC_scripted_gui.txt` | 在现有脚本化界面下方追加决议区入口和独立大窗，处理切页、选州、操作可用性、州帧和标记。 |
| `common/scripted_effects/LFC_scripted_effects.txt` | 在现有脚本效果下方追加接收目标州的派遣入口、共用的项目发起效果及实际发起时的校验。 |
| `common/decisions/LFC_decisions.txt`、`common/decisions/categories/LFC_decision_categories.txt` | 保留现有决议标识和运行中的项目，接新入口。全流程验证后再调整旧按钮的显示方式。 |
| `common/scripted_localisation/LFC_scripted_localisation.txt`、`localisation/LFC_l_simp_chinese.yml` | 根据选中州取州名和数据，新增状态及提示文本。保留工作区已有本地化改动。 |

| 信息 | 来源与处理 |
|---|---|
| 窗口是否打开、右栏页、当前选中州 | 新 GUI 状态。点地图只改当前选中州，切页只改右栏。 |
| 真正的远征目标 | 继续使用 `VAR_LFC_Rainforest_state`。筹备开始前记录目标，到取消、失败或成功时清理对应状态。选别的州查看与该目标无关。 |
| 远征状态及读数 | 使用 `FLAG_LFC_Rainforest_Acting` 和现有进度、人力、补给、装备变量。若筹备期间仍能再次发起，则补一个「筹备中」状态，并接通现有取消选项。 |
| 州归属和开发阶段 | 归属读取真实领土数据，开发阶段读取前哨站、定居点、发展中的殖民地、城市化等州修正。遗址规模独立读取州修正。项目可用性继续遵守现有决议条件。 |

## 接入现有玩法

### 远征

1. 右栏「筹备远征」先检查目标州、接壤、未勘探修正、队伍状态及现有资源条件。点击效果中再次检查，避免界面打开期间条件发生变化。
2. 在国家作用域内，从本次确认的目标州写入 `VAR_LFC_Rainforest_state`，然后触发 `LFC_event_forest.1`。旧州目标决议从 `FROM` 传入目标，新按钮从当前选州传入目标。两个入口共用发起逻辑。
3. 原决议的目标名单及接管脚本含州 `1206`，现有派遣目标赋值缺少 `1206` 分支。改用共用的目标传递后纳入实测，确认成功时接管的是 `1206`。
4. 保留现有筹备段和随机遭遇。远征成功仍走 `LFC_yulin_dikuai_control_effect`；失败仍走原事件。切换选州、切换遗物页、关窗或读档后，结果指向同一个远征目标。

### 各州开发与全国遗物应用

先做两个接线验证，分别选「推进基础建设」和「破译先驱者遗物」。这两项分别覆盖州目标与全国项目。

| 验证项目 | 现行脚本口径 |
|---|---|
| 推进基础建设 | 50 政治点，扣 200 资金，占用 3 民工，120 天后在指定州结算。 |
| 鼓励移民 | 50 政治点，扣 200 资金，占用 3 民工，120 天后在指定州结算。 |
| 地区城市化 | 50 政治点，扣 300 资金，占用 5 民工，120 天后在指定州结算。 |
| 遗迹勘探 | 50 政治点，扣 100 资金，占用 3 民工，90 天后在指定州抽取结果。 |
| 现有六项遗物应用 | 全国项目。各花 10 政治点和 100 遗物，修正持续 120 天。现行可用条件写的是余额严格大于 100，首轮验证记录余额恰好 100 的表现，阈值是否改动另行决定。 |

原版文档说明 `activate_targeted_decision` 会绕过决议本身的条件、冷却和一次性限制。它可以作为启动实验的候选，调用前仍要校验状态。需要实测 **扣费发生在哪一层、`complete_effect` 与到期结算是否照常触发、民工是否正常占用和释放**，再决定接线方式。

- **能沿用原决议生命周期时**，共用发起逻辑负责必要的条件和重入校验。扣费只在一个地方发生，决议负责确认过可复用的工厂占用、计时和结算。
- **某类项目无法做到行为等价时**，原型右栏先展示该项目的条件、花费和状态，由现有决议入口执行。最终交付前补齐大窗内的发起方式并通过对照测试。运行中的旧决议保留原结算路径。
- **项目结算与州绑定**。两州各自施工时，读数和完工效果分别落到正确州。全国应用用国家状态。遗迹勘探现有次数条件、显示文案与单次决议设置需要实测对照，GUI 首版按原规则接入。

## 实施顺序与验收

1. **地图交互原型**。生成 13 州的掩膜，用占位图搭主窗。逐州点选，检查边缘、共边、小州和装饰层遮挡。验证遗物余额能切页、地图能返回州详情、关闭再打开能恢复合理视图。
2. **远征闭环**。从一个符合条件的州发起原有远征。测试筹备取消、远征失败和成功。任务开始后查看其他州，再验证原目标变色、成为核心并出现前哨站。单独测 `1206` 的目标写入。
3. **项目接线**。各跑通一项州建设、全国遗物应用。对照旧入口检查扣费次数、民工占用、实际效果、结束时间和重复点击。验证同种州项目分别在两个州运行的显示及结算。
4. **接全部项目和状态**。接入移民、城市化、遗迹勘探及其余应用。用旧存档核对已有前哨站、在建项目、库存和已经受控的州。检查事件间切页、读档、失去控制权和条件变化后的按钮刷新。
5. **换正式美术**。先装正式地图和标记，再补插画。至少用 **1920 × 1080** 和较小窗口或较高界面缩放各检查一次，重点看右栏滚动、地名重叠、州点击区和关闭按钮。

**首版通过标准**。玩家能在同一个窗口完成「选州 → 派出远征 → 成功拿地 → 在该州发起开发」，也能从顶栏进入全国遗物应用。查看另一个州始终不会改写任务目标。已有事件和结算仍然可用，项目付出和收益与旧入口对得上。

## 当前实现与验证

- 已在现有 LFC 界面、图形、决议和脚本文件中接入地图大窗。入口位于「深入雨林」决议区。右栏支持州详情和全国遗物应用，远征定位按钮跟随实际任务目标。
- 已按 13 个州的省份轮廓生成测绘底图、点击精灵、归属色和描边，并生成四种地图标记。当前是浅色地图配深墨绿右栏的原型，遗迹插画仍待制作。
- 已接入现有的三步筹备和遭遇事件。新旧派遣入口共用目标写入，补齐 `1206`，取消、失败和成功各自释放目标。原决议可在取消或失败后重试。
- 已接入四项州开发和六项全国遗物应用。新旧入口把政治点与项目资源交给共用效果一次性扣除，计时、民工占用、奖励和修正继续由原决议处理。遗物余额恰好 100 时保留旧门槛。
- 静态检查覆盖控件与脚本绑定、本地化、58 张贴图路径、13 个互不重叠的州点击区，以及筹备、接管和项目引用。游戏内尚未验证。先检查窗口加载和中文素材路径，再实测强制启动是否确实激活对应州决议，两个州能否同时运行同种项目，以及遗物应用是否只扣一次费用并正确到期。原「先驱者遗迹开发署」决议入口可用于对照。
